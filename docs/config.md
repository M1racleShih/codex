## Fullscreen transcript scrollbar

Set `transcript_scrollbar = true` under `[tui]` to show a scrollbar on the right
edge of the conversation. Drag the thumb or click the track to move through loaded
history. Drag to the top to load an earlier page while keeping your place.

## Lifecycle hooks

Admins can set top-level `allow_managed_hooks_only = true` in
`requirements.toml` to ignore user, project, and session hook configs while
still allowing managed hooks from requirements and managed config layers. This
setting is only supported in `requirements.toml`; putting it in `config.toml`
does not enable managed-hooks-only mode.
